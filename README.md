# Afbeeldingen Lezergame

Publieke, gegenereerde illustraties voor het Lezergame-onderdeel van Leerplatform.

De app laadt de afbeeldingen via versievastgelegde externe URLs; de rasterbeelden worden niet in de JavaScript-bundel opgenomen.

De map `jungle-v1` bevat junglelandschappen en sprite-atlassen voor personages, spelvoorwerpen en lettersteunen. De definitieve prompts en herkomst worden bij de illustraties opgeslagen.
